# Trae.ai Landing Page UI/UX Design System

Re-engineering the entire interface to match the exact aesthetic, layouts, and UX tokens of Trae.ai's official landing page, while integrating Yudono's personal resume profile.

## 1. Aesthetic Core
- **Absolute Pitch-Dark Backing**: `#000000` base with soft glowing layers.
- **Electric Accent Palette**: Primary Brand Blue (`#2563eb` / `#3b82f6`) with Emerald Green / Cyan triggers (`#10b981` / `#22c55e`).
- **Header Structure**: High-contrast minimal typography, compact nav pills, green "Download Resume" action button.
- **Hero Typography Layout**:
  - Center-left stacked headline: "Ship Faster with Trae" -> "Ship Scalable Systems with Yudono".
  - Sleek CTA dual buttons: Primary Bright Green / Emerald button + secondary dark outline border button.
- **Section Layouts**:
  - Section headers with clear contrast ("New Trae Work" / "Loved by Devs").
  - Dynamic Grid Layouts showing structural workflows (like terminal telemetry logs or project cards).
  - High-density dark cards featuring subtle green or blue borders.
